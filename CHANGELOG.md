# Changelog

## 1.0.0 (2026-11-09)

First release.

- Chat window with replies streamed token by token and a resizable composer.
- First-run wizard, multiple accounts, one of them the default.
- Credentials in the OS keyring, or a Fernet encrypted file without one.
- Voice playback, voice input and hands-free auto-speak with a mute switch.
- Connection log, keepalive and automatic reconnect.
- `install.sh` installs into `~/.local/share/xiaozhi-talk` without root;
  `run.sh` runs straight from the checkout.
- Prebuilt AppImage, `.app` and `.exe` on the releases page.
